Website Profile XI PPLG
========================

Struktur:
- index.html   -> Home + About + Wali Kelas
- galeri.html  -> Galeri foto, video, video walas, tombol surat ucapan
- style.css    -> Styling + dark mode + animasi
- script.js    -> Dark mode, backsound, tab, modal, reveal animation
- assets/      -> Letakkan file media kamu di sini:
    * backsound.mp3   (musik latar)
    * video1.mp4, video2.mp4  (video kenangan)
    * walas.mp4       (video khusus wali kelas)

Cara pakai:
1. Ekstrak folder.
2. Ganti gambar/teks placeholder ([Nama Wali Kelas], dll).
3. Tambahkan file di folder assets/.
4. Buka index.html di browser.

Fitur:
- 2 menu (Home & Galeri) + submenu About
- Dark mode (tersimpan di localStorage)
- Backsound dengan tombol on/off (persisten antar halaman)
- Animasi reveal saat scroll, hover, modal, tabs
- Warna dominan abu-abu untuk XI PPLG, biru untuk Wali Kelas
- Responsive untuk mobile
